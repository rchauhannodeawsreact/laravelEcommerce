# Feature Documentation

## B2B Features

### 1. Vendor Management

#### Vendor Registration
- Multi-step registration process
- KYC (Know Your Customer) verification
- Bank account verification
- Document upload and verification
- Status tracking: Pending → Approved → Active

#### Vendor Dashboard
- Sales analytics
- Order management
- Product inventory
- Commission tracking
- Withdrawal management
- Report generation

#### Vendor Commission System
- Configurable commission percentage per category
- Automatic commission calculation on orders
- Commission statement generation
- Bulk settlement to vendors
- Commission dispute handling

### 2. Wholesale/B2B Pricing

#### Tiered Pricing
- Volume-based discounts
- Customer category-based pricing
- Time-based promotional pricing
- Bulk order discounts

#### Quote System
- Request for quote (RFQ)
- Vendor quote response
- Quote negotiation
- Quote to order conversion

#### Bulk Ordering
- Minimum order quantity (MOQ) per product
- Bulk order confirmation workflow
- Large order tracking
- Special handling for bulk shipments

### 3. Coin/Point System

#### Coin Earning
- **Purchase Coins**: Earn coins on every purchase (configurable rate)
- **Referral Coins**: Earn coins when referred user makes purchase
- **Sign-up Bonus**: Welcome bonus coins
- **Milestone Rewards**: Coins on reaching purchase milestones
- **Special Events**: Event-based coin bonuses

#### Coin Usage
- **Direct Redemption**: Redeem coins for discounts
- **Product Purchase**: Use coins to purchase products
- **Coin Transfers**: Transfer coins to other users
- **Coin Gifting**: Send coins as gifts to contacts

#### Coin Management
- Coin wallet with balance tracking
- Transaction history
- Expiry management (optional)
- Coin categories (purchase coins, referral coins, bonus coins)
- Lock/freeze functionality for pending transactions

#### Point Analytics
- User coin earning trends
- Popular redemption items
- Referral success rates
- Coin utilization metrics

### 4. Payment Processing with Paytm

#### Payment Gateway Integration
- Secure Paytm integration
- Multiple payment methods support:
  - Credit/Debit cards
  - Net banking
  - UPI
  - Wallet
  - EMI options

#### Payment Flow
- Order creation
- Payment initiation with Paytm
- Redirect to Paytm gateway
- Customer completes payment
- Callback handling
- Signature verification
- Transaction reconciliation

#### Wallet System
- User wallet with balance
- Wallet fund loading via Paytm
- Wallet usage for payments
- Wallet statement
- Refund to wallet

#### Payment Reconciliation
- Automatic transaction matching
- Settlement confirmation
- Payment status tracking
- Discrepancy resolution
- Audit trail
